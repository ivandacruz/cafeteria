# Cafeteria 🍵

Um site simples e elegante para uma cafeteria, apresentando um menu delicioso e uma experiência visual agradável.

![Cafeteria Preview](img/preview.png) <!-- Substitua por uma imagem real se disponível -->

## ✨ Funcionalidades

- **Menu Interativo**: Navegue pelos itens do menu com facilidade.
- **Design Responsivo**: Funciona perfeitamente em dispositivos móveis e desktop.
- **Galeria de Imagens**: Veja fotos dos pratos e do ambiente.
- **Vídeos Promocionais**: Assista a vídeos para uma experiência imersiva.

## 🚀 Como Usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/ivandacruz/cafeteria.git
   ```

2. Abra o arquivo `index.html` no seu navegador.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura do site.
- **CSS3**: Estilização e design responsivo.
- **JavaScript**: Interatividade e funcionalidades dinâmicas.
